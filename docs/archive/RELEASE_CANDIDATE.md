## Defects Fixed in This Candidate

Nine defects were found and fixed during the pre-launch audit. All were blocking.

| Commit | Defect | Severity |
|--------|--------|----------|
| `5ce5cf2` | Migration created `Conversation` before `ConversationFolder`, violating a foreign key — all database provisioning failed (P3018) | Critical |
| `c0b74ae` | Three unused imports failed the lint gate | Low |
| `2ad0b60` | Prisma schema and migration SQL diverged on `Conversation`, `ConversationFolder`, `MessageBranch`, `ConversationUsage` | Critical |
| `e122248` | Divergence continued across `Tool`, `ToolCall`, `AIMemory`, `SharedConversation`, `ConversationActivity`, `ConversationVersion`, `StreamingJob`, `ConversationTemplate`, `PromptTemplate` | Critical |
| `36d25ce` | Migration declared enum columns as `TEXT`; Prisma casts to native PostgreSQL enum types — every insert failed | Critical |

The schema defects meant Prisma generated a client for one database while the migration created a different one. Every Release 3 query failed at runtime. CI caught this; the failures were real, not flaky.

**Root cause**: the migration was hand-written rather than generated by `prisma migrate dev`, and nothing in CI detects drift between schema and migrations.

## Release Decision

### Option A — Launch Releases 1–2 now (recommended)

Ship auth, workspaces, projects, folders, assets, and billing. All are complete, tested, documented, and free of blocking defects. Hold Release 3 for a follow-up.

**Required before shipping**: confirm the test gate is green on `36d25ce`.

### Option B — Delay and complete Release 3

Estimated 5–8 engineering days:

1. Frontend types, API clients, hooks, and stores for conversations and messages
2. Chat pages (`/dashboard/chat`, `/dashboard/chat/[id]`) and components
3. SSE streaming endpoint
4. HTTP-level tests for the 13 Release 3 endpoints
5. SEC-01, SEC-02, PERF-01
6. `docs/api.md` and `docs/database.md` updates

### Not an option

Shipping the Release 3 backend without a frontend. Users would find no way to start a conversation. The API would serve no one.
